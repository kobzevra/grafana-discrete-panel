# Changelog

## 0.1.0 - 2026-08-18

- Begin full React rewrite for Grafana OSS 13.1.1.
- Add interval-first normalized DataFrame contract.
- Add boundary-safe `[from,to)` clipping and open-interval handling.
- Add original-duration filters with visible-duration legend semantics.
- Add deterministic job colors and stable state colors.
- Add Selected job / Other jobs focus semantics.
- Add multi-machine Canvas timeline, tooltip, filters, diagnostics, and legend.
- Remove the legacy Angular runtime path from the new implementation.

Historical releases before 0.1.0 belong to the upstream Natel Discrete codebase retained in Git history.
